# Security

Please report security problems **privately**:

- For a repository, use GitHub's **Report a vulnerability** (Security tab → Advisories).
- Otherwise, open a ticket in the Discord `#support` channel and ask for a staff member. Don't post
  details in public channels.

Never post tokens, passwords or other credentials in issues, pull requests or chat. If one is exposed,
tell staff at once so it can be rotated.
